In five days, the AI that makes this series asked to use a tool 2,009 times: 1,389 shell commands, 312 file reads. It ran none of them. My computer did.

The short version

  • A model only writes text. To read a file or run a command, it needs tools, and you hand it a menu: each tool's name, what it does, and its inputs as a schema.
  • It asks. When it needs one, it stops and sends a request: this tool, these inputs. In Anthropic's API the reply ends with stop_reason: "tool_use".
  • Your code runs it and reports back. The result goes back as a tool_result, matched to the request by its id. The model reads it and asks again, or answers. That loop is an agent.
  • The twist: your code decides. The model never runs anything, so your code can check the inputs, ask a human, or say no. In my studio, anything that spends money waits for me: one line of config.
  • Then and now. It started as OpenAI's function calling in June 2023. Today the Model Context Protocol is a shared standard for the menu, and its 2026-07-28 spec made it stateless.
