The File That Wouldn't Die

or: a grad-school P2P file system, from one laptop to the internet

Prefer to watch? Every animation in this post, narrated in about five minutes, with captions built in. The narration is a local AI clone of my voice.

In 2020 we built a peer-to-peer file system out of Python sockets and threads. Here's what it got right, what it got wrong, and every core idea you need to grow it from a laptop to real traffic: framing, locks, hashing, quorums, versions, tombstones, gossip, Merkle trees, erasure codes and consensus.

The short version, for whichever hat you're wearing

  • Split files into chunks, copy each chunk three times, and put the copies in different places.
  • Every change gets a version; every delete leaves a tombstone; every chunk carries a checksum.
  • Assume machines vanish: notice fast, route around them, and repair in the background.
  • TCP is a byte stream: length-prefix your messages, never search for an end marker.
  • Writes need a compare-and-set (an ETag and If-Match), or two uploads silently overwrite each other.
  • Pick R + W > N, and every read overlaps the latest write.
  • Consistent hashing means adding a server moves about 1/n of the data, not most of it.
  • Small metadata, big data: names and versions in a Raft group; bytes on replicated or erasure-coded storage.
  • Gossip for membership, Merkle trees for repair, zones for blast radius.
  • Durability is repair speed: the risk window is the time a chunk spends under-replicated.
  • Watch under-replicated chunks, p99 and disk, and practise killing a node.
  • Erasure coding halves storage cost for cold data, at the price of slower repair.

    framing · pseudocode
    import struct

async def send(writer, payload: bytes):
    writer.write(struct.pack("!I", len(payload)) + payload)   # 4-byte length, then the bytes
    await writer.drain()                                       # backpressure: wait if the socket is full

async def recv(reader) -> bytes:
    (size,) = struct.unpack("!I", await reader.readexactly(4))
    if size > MAX_FRAME:
        raise ValueError("frame too large")                    # never trust a length blindly
    return await reader.readexactly(size)                      # exactly that many, however TCP splits them

    04scale

    Where does a file live?

    We picked a random peer for the copy, then broadcast the whole directory so everyone could find it. Hashing makes the location computable instead:

    Interactive · 120 files, then a fourth server joins

    Each dot is a file, placed by the hash of its name and coloured by the server that owns it.

    Real 32-bit hashes of 120 file names, 16 virtual points per server. Consistent hashing moves about 1/n of the files; mod n moves most of them.

    put · pseudocode
    async def put(name, data, if_match, W=2):
    chunks = [data[i:i + CHUNK] for i in range(0, len(data), CHUNK)]    # 4 MiB pieces
    ids = [sha256(c) for c in chunks]                                     # the checksum is the chunk's name
    replicas = ring.owners(name, n=3, distinct_zones=True)

    acks = await first(W, [r.store(ids, chunks) for r in replicas], timeout=0.5)
    if len(acks) < W:
        raise Unavailable("not enough copies, try again")                 # never claim it was saved

    return await metadata.compare_and_set(                                # Raft: one truth per name
        name, expect=if_match, new={"chunks": ids, "version": if_match + 1})

      16

      2020 vs today, one page

      1. Messages on a TCP stream
        end marker (2020)length prefix

        Any bytes, no hangs. Cost: a 4-byte header.

      2. Many connections
        thread each + one lock (2020)asyncio + snapshots

        Readers never wait. Cost: async code everywhere.

      3. Where a file lives
        random peer (2020)hash ring, zone-aware

        Computable, and growth moves 1/n. Cost: virtual nodes to balance.

      4. How many copies
        2 (2020)3, W = 2, R = 2

        Survives one loss during repair. Cost: 3× storage.

      5. Two writers
        last writer wins (2020)compare-and-set

        No silent loss. Cost: clients retry.

      6. Deletes
        rename to "name *" (2020)versioned tombstones + GC

        We were right; add expiry. Cost: tombstones take space.

      7. Membership
        typed IP list (2020)seeds + gossip

        Servers come and go. Cost: tuning suspicion timeouts.

      8. Metadata
        broadcast to all (2020)a Raft group

        One truth per name. Cost: a majority must be up.

      9. Bit rot
        trust the disk (2020)checksums + Merkle repair

        Corruption is found, not served. Cost: hashing CPU.

      10. Getting in
        raw sockets on Wi-Fi (2020)HTTPS, tokens, a load balancer

        Safe to expose. Cost: one more hop.

      17

      The well-earned drink

      Every Brew Miles trip ends with one:

      1. Frame your bytes, and version everything, deletes included.
      2. Hash to place, copy to survive, and spread copies across failure zones.
      3. Make writes conditional and pick quorums that overlap.
      4. Gossip to notice, Raft to agree, Merkle trees to repair.
      5. Watch under-replication, and kill a server on purpose before one dies on its own.
